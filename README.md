# vlc-remote

Мобильный пульт для VLC на Windows-компьютере, подключённом к телевизору.
Телефон (Android) управляет воспроизведением по локальной сети напрямую через
HTTP-интерфейс VLC, а при наличии компаньона на ПК — также по Bluetooth и с
расширенными возможностями (выбор дорожек, аудиоустройство, монитор, сон ПК).

Статус: исследование и планирование. См. [docs/PLAN.md](docs/PLAN.md).
